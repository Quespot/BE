# Quespot API 에러 코드

모든 응답은 같은 봉투를 쓴다. 실패 시 `isSuccess=false`이고 **`code`로 분기한다**. HTTP 상태만으로 분기하지 말 것 — 같은 409라도 코드가 다르다.

```json
{
  "isSuccess": false,
  "code": "MISSION_409_011",
  "message": "아직 잠금 해제되지 않은 미션입니다. 이전 미션을 먼저 완료해 주세요.",
  "errorDetail": null
}
```

`errorDetail`은 입력 검증 실패(`COMMON_400_002`)일 때만 `{ "필드명": "메시지" }`로 채워진다.

Swagger의 각 API에는 프론트가 분기 처리해야 하는 도메인 에러만 `@ApiResponse`로 적혀 있다. 그 외는 이 표를 본다. 코드·메시지의 원본은 각 도메인의 `*ErrorCode` enum이다.

## 공통 처리 원칙

| 상황 | 처리 |
|---|---|
| `AUTH_401_003` (access token 만료·위조) | `POST /api/auth/reissue`로 재발급 후 원 요청 1회 재시도. 재발급도 `AUTH_401_004`면 로그아웃 |
| `AUTH_401_001` (토큰 없음) | 로그인 화면으로 |
| `AUTH_403_001` | 관리자 전용 API. 일반 사용자 화면에서는 나오면 안 됨 |
| `COMMON_400_002` | `errorDetail`의 필드별 메시지를 폼에 표시 |
| `COMMON_503_001` | 일시적 장애(DB 접근 실패 등). 재시도 버튼 |
| `COMMON_500_001`, `*_502_*` | "잠시 후 다시 시도" 안내 |

## COMMON (`GeneralErrorCode`)

| 코드 | HTTP | 메시지 | 발생 상황 | 프론트 처리 제안 |
|---|---|---|---|---|
| COMMON_400_001 | 400 | 잘못된 요청입니다. | 예약(현재 직접 던지는 곳 없음) | 일반 오류 안내 |
| COMMON_400_002 | 400 | 입력값 검증에 실패했습니다. | `@Valid`/`@Validated` 실패, 파라미터 타입 불일치 | `errorDetail` 필드별 메시지 표시 |
| COMMON_404_001 | 404 | 요청한 리소스를 찾을 수 없습니다. | 예약 | 일반 오류 안내 |
| COMMON_405_001 | 405 | 지원하지 않는 HTTP 메서드입니다. | 잘못된 메서드 | 개발 중 오류 |
| COMMON_500_001 | 500 | 서버 내부 오류가 발생했습니다. | 처리되지 않은 예외 | 재시도 안내 |
| COMMON_503_001 | 503 | 서비스를 일시적으로 이용할 수 없습니다. | DB 접근 실패(동시 요청의 UNIQUE 위반 포함), 인증 필터의 저장소 오류 | 재시도 버튼 |
